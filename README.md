# Rock-Paper-Scissors ✊✋✌️

**Rock-Paper-Scissors** is an interactive, browser-based implementation of the classic hand game, built as part of The Odin Project curriculum. It features custom-styled FontAwesome vector icons, soft aesthetic shadow effects, dynamic round/score tracking, and a game-over match limit.

<a href="https://cmatsagka.github.io/rock-paper-scissors/" style="color: inherit; text-decoration: underline; font-weight: 600;">🌐 View Live Demo</a>

![Rock Papers Scissors Preview Image](image.png)

---

## 🌟 Key Features

- **Interactive Icon Buttons:** Clean, minimalist icon-only controls for Rock, Paper, and Scissors with floating card shadow effects.
- **Automated Computer Logic:** Randomly generates valid choices for the computer opponent using randomized math functions.
- **Score & Round Management:** Dynamically updates round counts, running scores, and state messages up to a 5-point match limit.
- **Game-Over State:** Automatically calculates the final winner, announces the result, and locks further scoring loops once a threshold is reached.

---

## 🛠️ Tech Stack & Architecture

- **Markup:** Semantic HTML5 structure.
- **Styling:** Modern CSS3 featuring Flexbox, custom color palettes, and CSS filter adjustments for vector assets.
- **Logic:** Vanilla JavaScript (ES6) controlling game state variables, conditional logic, and DOM text updates.

## 🚀 Quick Start

Clone the repository:

```bash
git clone git@github.com:cmatsagka/rock-paper-scissors.git
```

Open the project directory:

```bash
cd rock-paper-scissors
```

## 📂 Project Structure

```text
rock-paper-scissors/
├── index.html       # Game markup and output display containers
├── styles.css       # Layout, theme styling, and shadow hover effects
├── script.js        # Core game logic, scoring engine, and event listeners
└── assets         # Preview screenshots and icon assets
```
